《灵墟归途3D》隐私政策

本政策说明单机与联网版本的数据处理。只有您选择联网功能、创建或登录账号时，才会启用下述账号与在线游戏服务；单机存档继续单独保存在设备上。

账号与身份验证

通过 Apple 或 Google 登录时，我们处理该平台提供的账号标识、邮箱（如提供）及用于验证身份的授权凭据。我们使用这些信息建立游戏账号、验证登录和管理账号安全，不要求或接收您在 Apple 或 Google 使用的密码。

使用邮箱注册时，我们处理邮箱、您输入的密码与验证码。密码以带盐的密码哈希保存；验证码有有效期和尝试次数限制。游戏会使用设备钥匙串保存登录所需的会话凭据，您可通过退出登录清除本机游戏会话。

Google 账号信息仅用于您选择的账号功能；我们对从 Google API 接收的信息的使用与转移遵循 Google API Services User Data Policy 及其 Limited Use 要求。

在线角色与多人对局

联网版本由游戏服务器保存角色标识、昵称、境界、修为、物品、材料、对局状态和结算记录，用于继续游戏、处理多人交互与防止重复结算。服务器处理游戏输入及必要的连接和请求信息，以运行对局、恢复连接和处理滥用。

同局玩家会收到多人游戏所需的角色昵称、外观、位置、战斗状态和对局动作等信息。账号邮箱、密码哈希、登录令牌及尚未向该玩家揭示的掉落内容不会作为多人画面数据发送给其他玩家。

现有单机存档不会自动上传为在线角色，联网角色与单机进度分开保存。单机版本的音量设置和本地存档仍由设备及其备份设置管理。

邮件与服务提供商

启用邮箱验证或找回密码时，验证码邮件需要通过配置的发信服务提供商投递。采用 Resend 发信时，接收邮箱、验证码邮件内容及投递信息会由 Resend 为投递目的处理，相关记录受其 隐私政策 约束。邮件用于您发起的账号操作，不用于营销订阅。

Apple、Google 和设备平台按照各自的隐私政策处理您在其平台上的身份验证。游戏账号与在线游戏服务部署于 XM LLC 管理的美国服务器。我们不使用游戏账号数据进行广告追踪或出售账号信息。

保存、删除与退出

账号和角色数据在提供账号及游戏功能所需期间保存。您可以在游戏的账号管理中申请删除在线账号及角色；删除需要重新验证身份，并处理相关第三方登录授权的撤销。未完成的对局和连接也会按服务端规则结束。

退出登录会结束相应的游戏登录会话，但不会删除服务器角色。删除在线账号不会删除独立的本机单机存档；删除 iOS App 会移除本机应用数据，“卸载 App”则可能保留文稿与数据。设备备份由 iOS 或 iCloud 的相关设置管理。

联系与政策更新

有关账号数据、隐私或支持请求，请联系 xm910llc@gmail.com。如果您主动发送邮件，我们会处理来信地址、内容和附件，以回复您的请求。游戏的数据处理方式变化时，本页会更新。
